Timing samples

What verify_chain actually measures: a live idhub signature check for every node walked (DPP and DTE alike), plus — for DPP nodes only — a live on-chain Besu re-verification that the anchored hash still matches (DTE/DCC/DFR/DIA are never anchored). Total cost scales entirely with how many nodes get walked, which depends on which credential you start from: a root credential with no upstream (chain_position=root) does one signature check and stops; the deepest end-of-chain credential (chain_position=end) walks every node behind it. The three rows are never averaged together below — see CHAIN_ANCHOR.md for what the anchor check itself does.
